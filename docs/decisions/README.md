# Decisions

One short file per decision that someone would otherwise have to rediscover — a dependency choice, a data model, a trade-off rejected. Name them `NNNN-short-title.md`.

```markdown
# NNNN — Title

**Date:** YYYY-MM-DD
**Status:** accepted | superseded by NNNN

## Context
What forced the decision.

## Decision
What was chosen.

## Consequences
What this makes easier, and what it makes harder.
```
